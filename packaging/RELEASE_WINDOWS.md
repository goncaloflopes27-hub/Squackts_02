Instalador de teste do SquackTS para Windows 10/11 de 64 bits.

Descarregue **SquackTS-Setup-<versão>-x64.exe**, abra-o e conclua a instalação. São criados automaticamente atalhos **SquackTS** no Ambiente de Trabalho e no menu Iniciar. A aplicação pode abrir no fim. Não é necessário instalar Python nem executar comandos.

A instalação é feita na conta atual. A base de dados e imagens ficam separadas do programa; reinstalar ou desinstalar preserva os dados.

O instalador é publicado depois dos checks Linux/Windows em Python 3.11/3.12, do build nativo Windows e do ensaio de instalação, atalhos, arranque, reinstalação e desinstalação com dados/imagens preservados. O ensaio inclui atualização desde o instalador publicado 0.3.0, migração de schema e caminhos com acentos, com plugin Windows nativo. Cada pacote identifica commit, versão e hash.

Esta é uma versão de teste operacional. Não tem assinatura digital; o comportamento de DPI e o uso no computador final continuam por validar. Pagamentos parciais, venda a prazo, levantamento em loja e cálculo de IVA ainda não estão implementados. O relatório e a evidência técnica estão incluídos na aplicação.

Esta revisão corrige bloqueios dos formulários e recuperação de restauro interrompido, acrescenta reembolsos e limites de valores. A suite tem 137 testes; a revisão detalhada está em docs/REVISAO_EXTERNA.md.

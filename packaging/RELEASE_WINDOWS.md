Instalador de teste do SquackTS para Windows 10/11 de 64 bits.

Descarregue **SquackTS-Setup-0.3.0-x64.exe**, abra-o e conclua a instalação. São criados automaticamente atalhos **SquackTS** no Ambiente de Trabalho e no menu Iniciar. A aplicação pode abrir no fim. Não é necessário instalar Python nem executar comandos.

A instalação é feita na conta atual. A base de dados e imagens ficam separadas do programa; reinstalar ou desinstalar preserva os dados.

O instalador é publicado depois dos checks Linux/Windows em Python 3.11/3.12, do build nativo Windows e do ensaio de instalação, atalhos, arranque, reinstalação e desinstalação com dados/imagens preservados. A reinstalação ensaiada usa a mesma versão, sem afirmar uma atualização entre versões distintas.

Esta é uma versão de teste operacional. Não tem assinatura digital; o comportamento de DPI e o uso no computador final continuam por validar. Pagamentos parciais, venda a prazo, levantamento em loja e cálculo de IVA ainda não estão implementados. O relatório e a evidência técnica estão incluídos na aplicação.
